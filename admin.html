Comment ça marche

  1. Créez une licence ci-dessous et cliquez « Ajouter au fichier ».
  2. Cliquez « Copier le fichier », puis « Ouvrir licences.json sur GitHub ».
  3. Sur GitHub, sélectionnez tout le contenu, collez, puis « Commit changes ».
  4. Envoyez la clé au client. Elle marche environ 5 minutes après l'enregistrement sur GitHub.
